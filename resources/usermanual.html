TM Data Quality Analyzer

User Manual — Version 2.7.0

TM Data Quality Analyzer examines IRIG 106 Chapter 10 PCM telemetry recordings and plots two data-quality metrics over time, per stream:

  • Frame Sync Lock — the percentage of each time window the decommutator held frame lock, plus a running count of missed frames.
  • Receiver AGC/SNR — receiver signal metrics embedded in the PCM frame, optionally converted to dB through a calibration profile.

1. Getting started

  1. Open the application menu with the ≡ button at the top left.
  2. Choose Open… (or press Ctrl+O) and select a .ch10 file — or simply drag and drop the file anywhere onto the window. Recently opened files are listed under Recent Files.
  3. The Configure Streams dialog appears, listing every PCM channel found in the recording. Configure the streams you want (see section 2) and press Process.
  4. Processing runs in the background with a progress dialog; results appear on the plot as each stream finishes.

2. Configuring streams

Each PCM channel row in the Configure Streams dialog has:

  • Process — include or exclude the stream from this run.
  • Mode — Frame Sync Lock Stats or Receiver AGC/SNR.
  • Settings (gear) — the per-stream setup dialog:
    • Frame sync: sync pattern, sync mask, and words per frame. These three fields can be saved to / loaded from a TOML file for reuse. Below the separator, Randomized, Data Rate, and Sample Rate are per-session inputs and are not saved.
    • SNR setup (SNR mode): word layout of the receiver channels within the frame, plus inversion/randomization flags.
    • Calibration (SNR mode): extract a calibration profile from a calibration run so raw counts convert to dB. Profiles apply to the current session only — they are never written to disk.

The dialog also selects the time channel used to timestamp all streams, and an optional start/stop time range to restrict processing.

3. Working with the plot

The chart fills the whole plot area — there are no control rows around it. Everything is either right-click on the plot or a small control overlaid on the chart, so the maximum amount of space shows data.

The right-click menu

Right-click anywhere on the chart. Entries stay disabled until a file has been processed.

  • Set Plot Title… — the title shown above the chart and carried into exports.
  • Plot File — after a batch run, picks which file's series are shown, or All files (overlaid). Disabled when only one file is loaded.
  • View Mode — for Frame Sync Lock data, switches the left axis between Lock Percentage and Accumulation (running missed-frame count). Disabled unless the data contains both.
  • Customize View… — rename series, change their colors, and show or hide individual series.
  • Show Legend — same toggle as the on-chart button below.
  • X Axis → Set Time Window… — type a start and stop time as DDD:HH:MM:SS to zoom to an exact span. Values outside the file's range are clamped to it and a note appears in the log. Reset Span returns to the full time range.
  • Y Axes → Set Left Max… / Set Right Max… — pin the top of the left (lock % or missed frames) or right (SNR dB) axis. Minimums always scale automatically. Reset clears both back to automatic.
  • Export… — the same export dialog as the main menu (see Import & export).

On-chart controls

  • Legend button — the small button at the chart's top-left shows or hides the legend. Your choice is remembered between sessions, and a hidden legend is also left out of exported images.
  • Legend — drag it anywhere inside the chart to keep it clear of the data. It starts in the top-right corner and lists one row per visible series.

Navigating

  • Zoom — scroll the mouse wheel over the chart to zoom the time axis.
  • Pan — click and drag left/right to move through time.
  • To return to the full view, use X Axis → Reset Span.

4. Understanding the metrics

Frame Sync Lock

Lock % is computed from bits actually observed: within each averaging window it is the share of bits that belonged to frames in lock. Missed frames count loss-of-lock events — the accumulation view shows their running total. A clean recording plots at a flat 100% with a flat accumulation line.

Receiver AGC/SNR

Receiver words embedded in each frame are averaged per window as raw counts, then converted once per window through the calibration profile (if attached). Readings outside the calibrated range clamp to the nearest calibrated step rather than extrapolating.

5. Templates & batch processing

A processing template captures one configured file's complete per-stream setup — modes, frame-sync settings, SNR layout, plus each series' custom name and color — independent of any file path.

Save as Template…

After processing a file, choose Save as Template… from the menu to write the template as a .json file.

Apply Template to Files…

  1. Pick a template file, then select any number of .ch10 files.
  2. Each file is validated up front: its PCM channel-ID set must exactly match the template's. Non-matching files are flagged with the missing/extra channels and skipped.
  3. In the batch dialog, optionally enable per-file export — for every processed file this writes a CSV plus two plot images (…_framesync_lock.png and …_missed_frames.png) to a folder you choose.
  4. All processed files stay loaded; use the Plot File selector to review each one or overlay them all.
Files must contain the same PCM channel IDs as the template. A file with even one extra or missing channel is rejected — this guarantees settings are never silently applied to the wrong physical channel.

6. Import & export

  • Export… — writes the current plot's data to CSV and/or the chart to an image (PNG, SVG, or PDF), and can save the log. Available from the menu and from the plot's right-click menu. A legend you have hidden is left out of exported images.
  • Import CSV… — loads a previously exported CSV straight onto the plot, with no reprocessing. Dropping a .csv onto the window does the same.

7. Interface & settings

  • Menu (≡) — every command lives in the single top-left menu, grouped into Process, Import/Export, Settings, and Help sections.
  • Sidebar — the panel on the left shows the processing log. It is shown by default; toggle it with the sidebar button next to the menu, or Ctrl+B. Its state is remembered between sessions.
  • Plot controls — the plot itself has no surrounding toolbars: right-click the chart for its menu, and use the on-chart legend button. See Working with the plot.
  • Theme — switch between dark and light themes from the Settings section.
  • Status bar — shows the loaded file and processing status.
