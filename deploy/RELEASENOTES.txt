tmDataQualityAnalyzer v3.1.0 - What's New
=================================

  Upgrading from v2.x - please read:

  - Your window preferences now start fresh. v3.0.0 brought over the
    preferences v2.x kept (the theme, whether the log sidebar and the legend
    are shown, your recent files, and the folders you last opened files
    from); v3.1.0 no longer does, and starts with the defaults instead. Your
    settings files - frame sync patterns, receiver parameter files and
    calibration step files - are kept, exactly as before.

    To keep your v2.x preferences, install v3.0.0 first and start it once
    (it brings them over), then install v3.1.0.

  - Upgrading from v3.0.0 keeps everything.

  Improved:

  - The application has its own icon again: in the title bar, the taskbar,
    Alt+Tab, Explorer and the Start menu. v3.0.0 showed a generic one.

  - The plot's single-key shortcuts - L, V, R, Backspace, Home, the arrow
    keys, + and - - now act only when pressed on their own. Ctrl+R or Ctrl+L
    no longer reset the view or hide the legend by accident. + still works
    with Shift, as most keyboards type it, and the keypad's + and - still
    zoom.

  - The user manual's pictures show this version. Some still showed the
    window of v2.14.2.


tmDataQualityAnalyzer v3.0.0 - What's New
=================================

  The application has been rebuilt on a new user interface framework. It does
  the same jobs, in the same windows, and gives the same answers: every
  recording we hold was processed by both v2.14.2 and v3.0.0, in 34 runs
  covering every sample rate and averaging period, both stream modes,
  calibrations and batch runs, and every exported CSV file came out
  identical, byte for byte.

  What happens when you install it:

  - It replaces v2.x rather than installing beside it. Run the installer and
    it upgrades your existing installation in place: same folder, same Start
    menu entry, and the .ch10 file association moves to the new version.

  - Your settings files are kept. Frame sync patterns, receiver parameter
    files and calibration step files you saved or edited in the settings
    folder are never overwritten, exactly as before.

  - Your preferences come with you. The first time v3.0.0 starts, it reads
    the preferences v2.x kept - the theme, whether the log sidebar and the
    legend are shown, your recent files, and the folders you last opened
    recordings and calibration files from - and carries on from there.

  - If you need the previous version, v2.14.2 stays available for download
    from the project's releases page.

  New and improved:

  - Configure Streams says what is wrong as it happens. OK and Process wait
    until every stream you checked is ready, and a line under the list names
    the stream that is not. A stream whose Mode you change has to be set up
    again for its new mode, rather than keeping settings meant for the other.

  - Apply Cal is unavailable, with a tooltip saying why, when a calibration
    cannot be extracted (a setting has a problem, or the recording has no time
    channel), instead of warning you after the click.

  - The window's maximize button offers Windows 11's snap layouts.

  - Export picks the image format from the file name you give it (.png, .svg,
    or a PDF otherwise), and Browse adds the right extension for you.

  - In the legend, a Receiver SNR channel shown by its short name gives its
    full name as a tooltip.

  - The user manual has been rewritten for this version, with every figure
    taken from the application itself. The plain-text UserGuide.txt is gone:
    the manual replaces it, in the application under Help > User Manual and,
    if you choose, as the full illustrated manual installed beside it.

  Fixed:

  - Extract Calibration now uses the time channel you chose in Configure
    Streams and the recording's own byte order (Legacy Chapter 10). It used
    to take the recording's first time channel whatever you had chosen.

  - A batch run's exported images no longer draw the legend's rows on top of
    one another.

  - A recording stored under a folder whose name has accented or other
    non-English letters can now be processed. It could be opened and listed,
    but processing it failed.

  - A Receiver SNR stream given a sync mask that ignores some of the low 16
    bits no longer loses bits from its receiver values (and from the
    calibrations extracted from it).

  - A calibration sweep that saturates at the top, with a turn-on spike before
    it, is no longer numbered one step off.

  - A calibration report whose unnamed channels all calibrated lists them as
    calibrated, not under "Fell back to linear calibration".

  Good to know:

  - Processing very large recordings takes about 5% longer than v2.14.2. That
    is the cost of a Windows security protection (the hardware shadow stack)
    that this version runs with and v2.x did not.

  - The window now opens at 1280 x 800.
