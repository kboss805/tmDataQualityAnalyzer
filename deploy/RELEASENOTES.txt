tmDataQualityAnalyzer v2.13.1 - What's New
=================================

  A packaging fix. The application itself is unchanged from v2.13.0 - if you are
  already running that version, nothing you do in the program will behave any
  differently.

  Fixed:

  - The installer was more than twice the size it needed to be. It carried a
    copy of the Microsoft Visual C++ redistributable installer that was never
    run: the Visual C++ files the application actually needs have always been
    installed alongside the program itself, so the extra copy did nothing but
    take up space - both in the download and on your disk afterwards.

    The installer is now 18.4 MB instead of 41.0 MB - less than half - and the
    installed folder is about 25 MB smaller. Nothing was removed that the
    application uses.

    The portable ZIP is unaffected - it never contained the extra copy.

  If you are installing over v2.13.0, the leftover file is removed for you as
  part of the upgrade. Your settings are untouched, as always.

  ---

  New in v2.13.0, if you are coming from an earlier version:

  - The plot is dramatically faster on large recordings - twelve channels of an
    hour at 10 ms resolution went from about a minute and a half per redraw to a
    small fraction of a second.
  - You can now set the MINIMUM of either Y axis, not just the maximum
    (right-click the plot, Y Axes). Setting the left minimum to 98 spreads a set
    of frame sync lock streams that all sit near 100% across the whole plot.
  - The Derandomize setting is now saved to and restored from frame sync pattern
    files.
  - Export... moved off the plot's right-click menu; it lives in the main menu
    under Import/Export. Exit is now the last entry in the main menu.
