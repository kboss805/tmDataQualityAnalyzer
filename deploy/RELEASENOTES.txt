tmDataQualityAnalyzer v0.8.0 - What's New
=================================

Architecture & UX Improvements
  - Extracted ProcessingCoordinator class from MainViewModel to own all worker thread lifecycle and batch sequencing
  - ProcessingSettings struct groups frameSync, polarityIdx, slopeIdx, scale, and receiverStates — replaces 5-parameter signatures across all processing entry points
  - ProcessingParams struct extracted to include/processingparams.h — single source of truth for all processing input parameters
  - TimeFields struct extracted to include/timefields.h — groups DOY/hour/minute/second for start and stop times
  - MainViewModel significantly slimmed — delegates all processing orchestration to ProcessingCoordinator
  - Batch results dialog: clear visualization of succeeded (green), failed (red), and skipped (gray) files after every batch run
  - View Plot combo integrated into batch results dialog — no separate plot selection prompt
  - Retry button auto-hides on click and only reappears if the retry run itself produces failures

Previous Releases

  - Plot hover tooltip: shows series name, time (DDD:HH:MM:SS), and dB value
