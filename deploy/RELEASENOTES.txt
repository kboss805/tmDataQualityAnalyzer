tmDataQualityAnalyzer v2.6.0 - What's New
=================================

  - New: You can now import a CSV file that this application exported earlier and
    load it straight into the plot, so you can review old data sets without
    re-processing the original Chapter 10 file. Use the new Import button on the
    toolbar (left of Export) or drag and drop a .csv file; Frame Sync Lock,
    Accumulated Missed Frames, and Receiver SNR series are restored to the correct
    axis and color automatically.

  - New: The plot legend now floats over the chart and can be dragged anywhere
    you like, so you can move it out of the way of the data you're looking at.
    It has a translucent background, remembers where you leave it for the
    session, and scrolls if you have a lot of series visible at once (for
    example, a Receiver SNR file with 48+ channels). It's included when you
    export a plot image.

  - Improved: The Configure Streams dialog has a cleaner layout: the Channel
    column shows the most identifying part of a long channel name instead of
    getting cut off at the start, and the Frame Sync Lock, Calibration, and
    Receiver SNR setup dialogs now look and behave more consistently with each
    other. The progress bar moved into its own window while a file is
    processing.

  - Improved: The Recent Files list now remembers imported CSV files alongside
    Chapter 10 files and reopens each in the right way. File > Open remains for
    Chapter 10 files; use Import for CSV.

  - Improved: Refreshed toolbar Export and Import icons that adapt to the light
    and dark themes.

  - Improved: If you try to import a CSV that wasn't produced by this application
    (or has no readable data rows), it is rejected with a clear message in the log
    instead of drawing meaningless data. Any malformed rows in a valid file are
    skipped and reported.

  - Fixed: If two configured streams happened to share the same channel name,
    renaming, recoloring, or reprocessing one of them could also change the
    other's data on the plot. Each stream is now tracked independently, even
    when the names match.

tmDataQualityAnalyzer v2.2.5 - What's New
=================================

  Receiver SNR step calibration is now complete and field-validated.

  - Improved: Step detection is now robust to real calibration recordings. The
    calibrated SNR steps from every receiver channel line up correctly in time,
    whether the receiver's raw count rises or falls with signal (normal or
    inverted polarity). A signal-generator turn-on transient at the start of the
    recording, and an optional operator down-ramp at the end, are automatically
    excluded — fixing the earlier "fat/skinny" time-skew and inverted-staircase
    behavior.

  - New: Clip Start / Clip End controls in the Apply Calibration dialog. Set the
    number of seconds to ignore at the start and/or end of the calibration
    recording before step detection, so any leading turn-on transients or
    trailing junk don't get mistaken for calibration steps.

  - Changed: Receivers driven past the calibrated range now read the calibration
    ceiling/floor (clamped to the nearest defined step) instead of diverging.
    This is the intended behavior for receivers that are far out of calibration.

  - Improved: The calibration extraction window now adapts to the frame rate
    (with a 100 ms floor) so fast minor frames calibrate cleanly.

  - Changed: All settings files (step-cal, receiver-parameter, and frame-sync
    TOMLs) are now tracked and shipped with the application.


tmDataQualityAnalyzer v2.2.0 - What's New
=================================

  - New: Non-linear step calibration for Receiver SNR. The Receiver SNR setup
    dialog gains an "Extract Calibration..." action that reads a calibration
    Chapter 10 file plus a step-config TOML (expected dB levels and dwell
    times), detects the step plateaus on each receiver channel, and builds a
    per-channel raw-to-dB profile. During processing those channels convert

    "Export Log (Text)" option alongside CSV data and the plot image, each with
    its own filename and location. The dialog lists the plot image first and
    defaults to image export.

  - Improved: Switching the left axis between "Framesync Lock (%)" and
    "Accumulated Missed Frames" now keeps your per-stream selection instead of

    separator line above the OK/Cancel buttons for clearer visual grouping.

tmDataQualityAnalyzer v1.0.0 - What's New
=================================

This is the initial public release of tmDataQualityAnalyzer, a Qt 6 desktop
application for analyzing telemetry data quality in IRIG 106 Chapter 10 (.ch10)
recording files. The application visualizes Frame Sync Lock statistics and
Receiver SNR/AGC data versus time, and exports results to CSV and image formats.


Frame Sync Lock Analysis
  - Frame Sync Lock mode: measures per-stream frame synchronization lock percentage
    over time directly from the decoded PCM bitstream — no receiver parameters required
  - Bit-serial frame sync scanner with acquire/lock phases: confirms a configurable
    number of in-phase syncs (min syncs) before declaring lock
  - Off-phase false-positive rejection while locked: sync patterns that appear inside
    pseudo-random (PRN) data words no longer disrupt frame collection, eliminating
    spurious lock oscillation on clean randomized streams
  - Automatic lock loss and re-acquisition when a true frame sync is missed
  - Bit-span lock percentage: lock % is computed from the actual number of frame-sized
    bit slots traversed versus frames detected — the lock figure does not depend on
    an exact TMATS/data-rate value
  - Configurable frame sync pattern (hex), sync mask (hex), bits per frame, RNRZ-L
    randomization, data rate (Mbps, or Auto from TMATS), and averaging window
    (1 s / 100 ms / 10 ms)
  - Lock percentage plotted against actual file time (DDD:HH:MM:SS)


Receiver SNR / AGC Analysis
  - Receiver SNR mode: extracts calibrated receiver-channel AGC values from the minor
    frame using a Receiver Parameters TOML (word map + calibration)
  - Configurable polarity, voltage slope/range, scale (dB/V), receiver count, and
    channels-per-receiver
  - Voltage-to-dB conversion with per-receiver-channel plotting on a dedicated
    right-hand Y-axis
  - Averaging windows: 100 Hz, 10 Hz, 1 Hz


Multi-Stream Processing
  - Per-stream configuration: one row per PCM channel in the Configure Streams dialog,
    each independently set to Receiver SNR or Frame Sync Lock mode with its own setup
  - Concurrent processing: a single file-reader thread reads the Chapter 10 file once
    and routes packets to per-stream queues; each stream is processed on its own worker
    thread in parallel
  - Single-pass I/O: the file is read exactly once regardless of stream count —
    a large speedup on multi-stream, multi-gigabyte recordings
  - Results accumulate into an in-memory plot; each completed stream is added as it
    finishes
  - Bounded per-stream queues and cooperative cancellation: cancel cleanly stops the
    reader and all workers without deadlock


Plot Window
  - Dual Y-axis plot: Frame Sync Lock (%) on the left axis, Receiver SNR (dB) on the
    right axis, with time (DDD:HH:MM:SS) on the X axis
  - User-specified plot title
  - Mouse wheel zoom and click-drag pan on the X axis
  - Time-window controls to auto-zoom and move the X axis to a user-defined range
  - Y-axis auto-range with manual min/max override
  - Per-series visibility toggle via legend tree with tri-state checkboxes
  - Automatic color palette assignment by receiver; channels within the same receiver
    share a hue family
  - Light and dark theme support synchronized with the application theme


Configuration & Files
  - TOML-based configuration: Frame Sync parameters (pattern, mask, bits per frame)
    and Receiver SNR parameters (word map, calibration) stored in separate TOML files
  - Per-stream load/save of configuration files directly from the stream setup dialog
  - Per-file-type directory persistence for Ch10 and TOML file dialogs across sessions
  - Recent files list (up to 5 entries) with persistence across sessions


Data Export
  - CSV export: timestamped frame sync lock percentages and/or SNR values with
    labeled column headers
  - Image export: plot window saved as SVG, PNG, or PDF
  - Unified export dialog: select export types, filenames, and output directories
    in a single action


Error Checking
  - All input fields validated with inline log messages for invalid entries
  - Frame sync pattern validated to contain only hexadecimal characters
  - Frame sync pattern length validated against the configured frame length


Application Installer & Portable Package
  - Inno Setup EXE installer: supports installation to Program Files (admin) or a
    user-chosen directory (non-admin) via the privileges override dialog
  - Installer preserves existing user TOML files on upgrade; a fresh copy of
    default.toml is installed alongside as default_new.toml for application-driven
    TOML merge/upgrade logic
  - Portable ZIP: flat layout with a "portable" marker file; QSettings are redirected
    to the application directory so no registry or AppData writes occur
  - Optional code signing via SHA-1 certificate thumbprint (SIGN_CERT_SHA1)


Developer / Build
  - VS Code debugging configured for the Eclipse CDT GDB adapter (Debug/Release launch
    configurations for both the application and the test suite)
  - Automated unit tests using the Qt Test framework covering constants, frame
    processor, stream config dialog, processing coordinator, export dialog, and
    plot view model
  - Single-script release build (deploy/build_release.ps1): qmake → mingw32-make →
    windeployqt → optional code signing → portable ZIP → Inno Setup installer
  - Version is defined once in include/constants.h (AppVersion struct) and propagated
    automatically to the .pro file, Windows resource file, and installer script
