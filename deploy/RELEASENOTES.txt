tmDataQualityAnalyzer v2.14.2 - What's New
=================================

  The application itself is unchanged from v2.14.1. This release corrects three
  of the files that ship alongside it and one piece of the documentation.
  Nothing about how streams are processed, calibrated, plotted or exported has
  changed.

  Changed:

  - The three supplied frame sync pattern files now state the Derandomize
    setting instead of leaving it unmentioned. Loading PRN-11, PRN-15 or the
    receiver default now sets that box - previously it left whatever you had
    already ticked, so the result depended on what you had been doing before.

    All three state Derandomize OFF, which is what these supplied patterns
    target. If your stream is RNRZ-L you still tick the box after loading, as
    before. A pattern file you saved yourself is unaffected and keeps the old
    leave-it-alone behaviour.

  Fixed:

  - The user guide said the Derandomize setting was "deliberately not saved"
    when you save a frame sync pattern file. That stopped being true in v2.13.0,
    when it started being saved alongside Invert Data. The guide now describes
    what a saved pattern file actually carries.

  - The user guide now says what installing a new version does to your settings
    folder: nothing. Your own pattern files, receiver parameters and calibration
    step files are never overwritten by an upgrade and are kept when you
    uninstall. A new setting added to a supplied default file reaches a fresh
    installation rather than an existing one, and your files stay readable
    either way.

  Under the hood:

  - The installer is now tested by installing it on a clean machine - a
    throwaway Windows Sandbox that has never held this application - which
    checks that it runs somewhere with no Qt installed, that the first run
    leaves your settings alone, and that uninstalling removes the program while
    keeping the settings folder.
