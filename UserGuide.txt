1. INTRODUCTION
================================================================================
tmDataQualityAnalyzer is an advanced desktop application designed for analyzing
telemetry data quality from IRIG 106 Chapter 10 (.ch10) data files. By processing
Pulse Code Modulation (PCM) streams, the tool allows test engineers and analysts 
to visualize critical data metrics like Framesync Lock Percentages, Accumulated 
Missed Frames, and Receiver Signal-to-Noise Ratios (SNR) over time to easily 
identify dropouts, disconnects, or signal degradation.

================================================================================
2. QUICK START
================================================================================
1. Load a File: Use the File menu or the open icon in the toolbar to load a
   .ch10 file. The Configure Streams dialog opens automatically, listing one row
   per PCM channel found in the file.
2. Select the Time Channel: Choose the Time Channel from the dropdown at the top
   of the Configure Streams dialog.
3. Configure Streams: For each PCM channel you want to analyze, check Process,
   choose its Mode (Frame Sync Lock or Receiver SNR), and click the gear icon to
   set its sync/calibration parameters and averaging window.
4. Process: Click "Process" to read the .ch10 file and generate the data quality
   plots. Each stream is added to the plot as it completes.
5. Export: Click "Export" to save your plots as an image or extract the
   underlying data to a CSV.

================================================================================
3. PROCESSING SCOPE & AVERAGING WINDOW
================================================================================
The application processes the entire .ch10 file in a single pass. You control the
resolution of the output per stream via the Averaging Window in that stream's gear
dialog:

- Averaging Window: Choose 1 s, 100 ms, or 10 ms. The lock percentage and SNR
  values are averaged over this period to produce one plotted point per window.
  Smaller windows reveal finer detail (brief dropouts) at the cost of more points.

To focus on a specific time span after processing, use the plot's X-axis zoom/pan
and the time-window controls rather than restricting the input.

================================================================================
4. STREAM CONFIGURATION
================================================================================
While the application will parse the TMATS (Telemetry Attributes Transfer 
Standard) header to provide initial guesses for channel setups, TMATS should 
only be used as a guide. All parameters used for processing are strictly driven 
by the Stream Configuration dialog.

When you click "Configure Streams", you can selectively enable or disable 
individual sub-streams. For each active stream, you must define its operation 
mode:

--- Frame Sync Lock Mode ---
Use this mode to evaluate the structural integrity of the PCM stream.
- Frame Sync Pattern: The expected synchronization bit pattern.
- Frame Sync Mask: The mask applied to the sync pattern.
- Bits in Frame / Words in Frame: The structural dimensions of your minor frames.

Tip (Apply to All Streams): If you have multiple streams using the same sync
parameters, check the "Apply to all Frame Sync Lock streams" box at the bottom
of the dialog. This will instantly copy the current stream's sync settings to
all other active streams configured in Frame Sync Lock mode.

--- Receiver SNR Mode ---
Use this mode to evaluate raw signal strength.
- Configure the calibration slope and scale offsets specific to your receiver 
  equipment.

Tip (Apply to All Streams): Similar to Frame Sync mode, check the "Apply to all
Receiver SNR streams" box to broadcast your calibration settings to all other
active Receiver SNR streams.

================================================================================
5. ANALYZING DATA
================================================================================
Once processing completes, the plot area will populate with your stream data.

- Framesync Lock (%): Displays the percentage of successful syncs within the 
  time window. Drops in this graph indicate noisy data or signal loss.
- Missed Frames: Displays an accumulating sum of dropped minor frames. Look for 
  steep upward slopes to identify prolonged physical disconnects or massive 
  dropouts.
- Receiver SNR: Plots the calibrated signal-to-noise ratio.

Interactive Controls:
- Use the Customize Plot Series dialog (toolbar) to toggle the visibility of
  specific streams, receivers, or individual L/R/C channels. Switch the left
  axis between Framesync Lock (%) and Accumulated Missed Frames with the
  left-axis view toggle.
- Zoom / Pan: Click and drag the plot to pan, or use your scroll wheel to zoom 
  into specific anomalies.

================================================================================
6. EXPORTING RESULTS
================================================================================
To share your findings or process the data in external tools (like MATLAB or 
Excel), use the Export feature.

- Export to Image: Saves the current visual state of the plot (including your
  current zoom/pan window) to a PNG, SVG, or PDF file. (PNG includes the legend
  panel beneath the chart.)
- Export to CSV: Writes the plotted data points into a comma-separated text file,
  organized by timestamp and stream.
- Export Log: Optionally saves the contents of the log window to a text file.
